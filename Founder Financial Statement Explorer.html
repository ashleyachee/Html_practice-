How this activity works
  • Work through the transactions in order. Each one asks three questions: one for each statement.
  • Choose an answer for all three questions, then select Check my answers. You can change an answer and check again as many times as you like; the score counts first attempts only.
  • If you get stuck, Show me the answers reveals the correct choices with an explanation so you can keep moving.
  • Posting a transaction updates the three statements below the questions. You can revisit any posted transaction from the ledger list.
  • Everything works with a keyboard: Tab moves between controls, arrow keys move within a set of answer choices, and Enter or Space activates a button.

    How the three statements connect

      Teaching note. This activity uses simplified U.S. GAAP–style treatments so the links between the statements stay visible. Real-world details vary: capitalization thresholds, depreciation methods and useful lives, revenue-recognition timing, and whether cash flows are presented using the direct or indirect method are all set by company policy, by the reporting framework in use (for example U.S. GAAP or IFRS), and in some cases by tax rules in a particular jurisdiction. Interest, income taxes, payroll taxes, and inventory are left out on purpose. This is a learning model, not accounting or tax advice.
